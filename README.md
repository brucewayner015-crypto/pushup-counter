Связка 0.1.0 — своя служба на вашем сервере, которая собирает несколько VPN-подписок в одну ссылку, переименовывает и скрывает серверы. Ссылку открывают Лазейка и приложения на телефоне (Happ, v2rayNG, Hiddify, Streisand). Домен не нужен: Связка сама получает бесплатный сертификат Let's Encrypt прямо на IP-адрес сервера.

Пробная версия: проверена в тестовом окружении, на настоящем сервере ещё не запускалась.

**Установка** — подключитесь к серверу по SSH и выполните одну команду:

```
curl -fsSL https://raw.githubusercontent.com/brucewayner015-crypto/pushup-counter/svyazka/install.sh | sudo bash
```

Установщик скачает программу и сверит контрольную сумму, выберет порт (443, а если он занят — например, Xray от AmneziaVPN — 8443), откроет порты в ufw/firewalld, получит сертификат и покажет адрес панели, пароль и ссылку подписки. Нужен Linux с systemd (Ubuntu, Debian и т. п.) на x86_64 или arm64. Порт 80 Let's Encrypt использует для проверки раз в несколько дней — если у хостера есть свой файрвол (Security Group), откройте в нём TCP 80 и порт Связки.

**Дальше**

1. Откройте адрес панели в браузере и войдите паролем из установщика.
2. «Добавить источник» — вставьте ссылку на подписку. Так для каждой подписки, которую нужно объединить.
3. «Имена и фильтры» — правила переименования (`Netherlands → Нидерланды`) и слова, по которым серверы скрываются. Любой сервер можно скрыть галочкой в списке «Серверы».
4. «Копировать» или «QR-код» — добавьте ссылку в Лазейку («Серверы» → вставить → «Добавить») и в приложение на телефоне.

Служебные записи подписок («Осталось 5 дней», «Наш сайт») скрываются сами. Если источник временно недоступен, Связка отдаёт его последнюю копию.

**Команды на сервере**

- `sudo svyazka info` — адрес панели и ссылка подписки
- `sudo svyazka passwd` — новый пароль панели
- `sudo journalctl -u svyazka -n 50` — журнал службы
- обновить — та же команда установки (настройки сохраняются)
- удалить — `curl -fsSL https://raw.githubusercontent.com/brucewayner015-crypto/pushup-counter/svyazka/install.sh | sudo bash -s -- uninstall` (добавьте `--purge`, чтобы удалить и данные)

**Безопасность.** Панель открывается только по секретному адресу и паролю; после пяти неверных паролей вход с этого адреса блокируется на время. Ссылка подписки тоже секретная — если она утекла, «Настройки» → «Заменить ссылку». Служба работает от отдельного пользователя без прав root, данные лежат в `/var/lib/svyazka`.
