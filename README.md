Лазейка 0.1.6 — личный VPN-клиент для Windows 10/11: mihomo (VLESS/XHTTP/Reality, AmneziaWG до 3.1, подписки) и zapret от Flowseal с умной маршрутизацией.

Пробная версия: на настоящем Windows ещё не проверялась.

**Первый запуск**
1. Запустить `Lazeyka.exe`. SmartScreen: «Подробнее» → «Выполнить в любом случае» (exe без цифровой подписи). Права администратора — один раз.
2. Программа ставится в `C:\ProgramData\Lazeyka`, ярлык «Лазейка» — на рабочем столе и в «Пуске».
3. Вставить ссылки `vless://`, `vpn://` из AmneziaVPN, конфиг AmneziaWG или адрес подписки → «Распознать» → «Добавить».

mihomo и zapret скачиваются при первом использовании с официальных релизов GitHub и сверяются по SHA-256.

SHA-256 `Lazeyka.exe`: `e0af24be975c69d8fadd8d7048a6651d2a95406a1395e98c5e28ca8c3e9c2546`

**Подписки и Связка.** Лазейка показывает серверы подписки с теми именами, которые отдаёт подписка, и не берёт на этом компьютере российские и служебные «серверы» (список слов — в «Серверы» → подписка → «Название и фильтр»). Объединять подписки, переименовывать и скрывать серверы для всех устройств — в Связке: https://github.com/brucewayner015-crypto/pushup-counter/tree/svyazka

**mihomo-windows-amd64-v1-v1.19.34.zip** — официальная сборка mihomo 1.19.34 от MetaCubeX (лицензия GPL-3.0, исходники: https://github.com/MetaCubeX/mihomo/tree/v1.19.34). Нужна, только если Лазейка не может скачать mihomo с GitHub сама: положите архив в папку «Загрузки», Лазейка сверит его контрольную сумму с GitHub и установит.
